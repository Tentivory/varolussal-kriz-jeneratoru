# VAROLUŞSAL KRİZ JENERATÖRÜ

## Dünyanın En Ciddi, En Abartılı, En İşe Yaramaz Projesi

Bu repository, insanlığın binlerce yıllık varoluşsal sorunlarını çözmek için tasarlanmıştır. Aslında çözmez. Sadece üretir. Daha çok kriz. Daha derin. Daha saçma.

### Nasıl Çalışır?

```bash
python kriz_jeneratoru.py
```

Program senden kaç kriz istediğini sorar. Sonra çok ciddi bir şekilde düşünür (yani uyur) ve rastgele bir varoluşsal kriz fırlatır. Çalışır. Gerçekten çalışır. Denemeni öneririm, belki hayatın anlamını bulursun. (Bulamazsın.)

### Neden Var?

Çünkü GitHub'da patates yok. Çünkü saçmalık bir sanattır. Çünkü birileri "bu ne işe yarar?" diye soracak ve cevap "hiç" olacak. Bu da bir cevaptır.

### Özellikler

- Gerçek Python kodu
- Gerçek `time.sleep()` ile derin düşünce
- Abartılı Türkçe krizler
- Hiçbir şey çözmez ama hissettirir

### Uyarı

Bu programı çalıştırdıktan sonra hayata küsersen sorumluluk kabul etmiyoruz. Sorumluluk zaten yok.
